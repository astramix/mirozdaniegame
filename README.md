# Мироздание

Процедурный симулятор Создателя: от первичной жизни до планетарной цивилизации. Религии, языки, экономики и государства рождаются из условий мира, а культуры по-своему называют Создателя, почитают его, отрицают или восстают против него.

Godot 4 + C#. План: `docs/PLAN.md`. Архитектура: `docs/ARCHITECTURE.md`. Правила проекта: `RULES.md`.

## Быстрый старт

```
dotnet run -c Release --project src/Mirozdanie.Cli -- run --seed 42 --years 1000 --script examples/drought-prophet.json --out out
```

Хроника мира — `out/42/chronicle.md`, карты — `out/42/*.png`. Игра: `dotnet build game/Mirozdanie.Game.csproj && godot --path game`.

Управление: экран сотворения → «Сотворить» → **лепка мира** (кисть и силы Земли, всё бесплатно, Ctrl+Z — отменить) → «Зародить жизнь» (мир стоит на паузе). Пробел — пауза, 1/2/3 — скорость. Левая кнопка с протяжкой вращает планету, колесо приближает. Выберите силу в книге внизу и кликните по планете; Shift — наложить ещё раз, Esc или правая кнопка — отменить. Клик по народу — его карточка, «Говорить» — разговор. «Сохранить»/«Загрузить» — вверху; миры лежат в `user://worlds/`.

Сфера «Земля» в книге сил: кисть (поднять, опустить, выровнять, сгладить, изрезать, увлажнить, иссушить, согреть, остудить, удобрить, истощить) — зажмите левую кнопку и ведите по планете, `[` и `]` меняют размер; вращать — правой или средней кнопкой. Силы: хребет, перешеек и пролив (два клика), остров, погружение, река, озеро, вулкан, оазис, пустыня, ледник, таяние (клик), дрейф материка (клик по суше, затем — куда), климат мира и уровень моря (сразу). Флажок «как природа» растягивает перемену на века.

Тесты: `dotnet test src/Mirozdanie.Core.Tests`. Бюджеты: `dotnet run -c Release --project src/Mirozdanie.Bench -- --budget`. Разнообразие: `dotnet run -c Release --project src/Mirozdanie.Cli -- diversity --worlds 30`.
