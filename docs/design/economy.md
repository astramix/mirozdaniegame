# Э5 (скелет). Хозяйство, торговля, энергия

**Роль.** Превращает среду в пищу и излишек: излишек кормит храмы, вождей и войны, голод кормит толкования.

**Модели.**
- Способ хозяйства (`Subsistence`) выводится из клетки и знания: рыболовство (берег/река, рыба > 0,4), кочевое скотоводство (степь/саванна, есть крупные травоядные виды в клетке), земледелие (одомашниваемые растения + `Knowledge > 0,25`, событие `AgricultureAdopted`), иначе собирательство. По мотивам Diamond (1997).
- Мальтузианский предел: `K = area_food · yield(subsistence) · (1 + tech)`; урожай × климат года (засуха, чудо). Голод `Famine`, когда `Food/need < 0,7` (Malthus 1798; Ashraf & Galor 2011 — в мальтузианскую эпоху технология даёт плотность, а не доход).
- Торговля по гравитационной модели (Tinbergen 1962): `T_ij = G·M_i·M_j / d_ij²`, где M — излишек, d — расстояние по сетке (море ×0,5 для групп-рыболовов). Пары с `T_ij` выше порога образуют торговую связь (`TradeRoute`); связь повышает контакт для распространения веры и знания и даёт обоим `+0,1·T_ij` пищи.
- Энергия на душу: собиратели 120 Вт (пища + огонь), скотоводы 250, земледельцы 400, государственные общества 600 (оценки по Cook 1971, «The flow of energy in an industrial society», упрощённо). Суммарная мощность P = Σ Pop·w; уровень Кардашёва по Сагану: `K = (log₁₀P − 6)/10`.
- Храмы (`TempleBuilt`): при излишке и обрядности > 0,6 — святыня становится храмом, удваивает CRED веры в радиусе.

**Слушает:** засухи, дожди, чудеса урожая, войны (разорение). **Порождает:** `Famine`, `AgricultureAdopted`, `TradeRoute`, `TempleBuilt`, `Discovery` (письменность, металлургия, астрономия), `KardashevMilestone`.

**Заглушки:** деньги, рынки, Рикардо, граф открытий — только 5 открытий-порогов по знанию.
