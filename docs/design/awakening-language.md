# Э3. Пробуждение, группы, языки, имена

## Переход особи → группы

В момент `Awakening` (вид s*):
- выбираются 6–12 эко-клеток с наибольшей биомассой s* (с расстоянием между ними ≥ 4 клетки) — там рождаются первые группы (`GroupFormed`);
- население группы стартует с 60–150 (полосы охотников-собирателей; число Данбара ~150, Dunbar 1992);
- культура группы выводится из генома вида и среды: агрессивность ← `Diet`, коллективизм ← `Sociality`, любознательность ← `Cognition`, набожность ← 0,4 + 0,4·(сезонная изменчивость среды) (непредсказуемая среда — больше склонности к ритуалу, Malinowski 1948; спорно) и т. д.;
- у всех групп общий праязык вида; особи вида s* убираются из пула (дальше вид живёт как группы), остальные виды остаются популяциями (фауна для охоты).

## Группа (SoA в `Groups`)

Поля: `Cell`, `Pop`, `Food`, `Knowledge`, культура (6 float: агрессивность, коллективизм, иерархия, открытость чужакам, отношение к знанию, набожность), `LanguageId`, `ReligionId`, `CultId` + `CultShare`, латентные отношения к Создателю (B, P, G, N, D), память толкований (кольцо из 8), эпитеты Создателя, `PolityId`, `Subsistence`, `Founded`, `ParentGroup`, `Alive`.

Демография: мальтузианская логистика `Pop' = Pop + r·Pop·(1 − Pop/K)` с `r = 0,02`, `K = food_capacity(cell, subsistence, tech)`; голод при `Food/need < 0,7` повышает смертность.

Деление (fission): при `Pop > 2·F_max` (F_max = 500 для собирателей, 3000 для земледельцев, растёт с иерархией) 30–45 % населения уходит в свободную клетку в радиусе 3 с лучшей ёмкостью (`GroupFissioned`). Дочерняя группа наследует язык (пока как диалект), религию, культуру с шумом.

## Фонология праязыка

Инвентарь — подмножество универсального набора, отфильтрованное анатомией вида:

| Признак анатомии | Влияние |
|---|---|
| `Lips < 0,3` | нет губных (p b m f v w) |
| `TongueAgility < 0,4` | нет r, l слит с r, мало переднеязычных |
| `Nasality > 0,6` | больше носовых, есть ŋ; `< 0,2` — носовых нет кроме n |
| `LarynxDepth < 0,4` | 3 гласных (a i u), иначе 5–7 |
| `Mass` большой | есть увулярные q, χ (низкие частоты) |

Размер инвентаря растёт с `Cognition` (но мы не утверждаем реальную связь — это вкусовой параметр, отмечено в NOTES). Слоговая структура: шаблон из {CV, CVC, CCV, CCVC, V} с весами; ударение: начальное/предпоследнее/конечное; порядок слов: SOV/SVO/VSO (влияет на порядок частей в составных именах: «огонь-бросающий» vs «бросающий-огонь»).

## Лексикон

~70 базовых понятий (`Concept`): вода, огонь, солнце, луна, небо, земля, камень, дерево, река, гора, море, дождь, ветер, молния, смерть, жизнь, бог, дух, враг, народ, отец, мать, ребёнок, кровь, пища, зерно, зверь, птица, рыба, звезда, ночь, день, рука, глаз, сердце, слово, великий, малый, старый, новый, добрый, злой, сильный, молчащий, гневный, дающий, бросающий, святой, война, мир, вождь, страна, город, дом, путь, дар, кара, свет, тьма, сон, голос, судья, красный, белый, чёрный, холод, жара, голод, хлеб, огонь-с-неба (метеорит), трясение, мать-земля…

Корень — 1–2 слога по фонотактике. Звукосимволизм (дешёвая идея из ideas.md): у понятий «малый», «ребёнок», «свет» чаще передние гласные (i e), у «великий», «тьма», «гора» — задние (a o u) — частотный код Охалы (Ohala 1984).

## Звуковые законы

Регулярные правила, применяются ко всему словарю языка-потомка:
- оглушение конечных звонких (b d g → p t k / _#);
- озвончение между гласными (p t k → b d g / V_V);
- палатализация (k g → tʃ dʒ / _i,e);
- лениция (p → f, t → s, k → x);
- выпадение конечного безударного гласного;
- синкопа (выпадение срединного гласного между одиночными согласными);
- сдвиг гласных (a → o, o → u, u → y …);
- упрощение групп согласных (CC → C в начале слова);
- дебуккализация (s → h);
- носовая ассимиляция (n → m / _p,b).

Каждое правило — функция над последовательностью фонем; результат проверяется на непустоту.

Глоттохронология (Swadesh 1955; Lees 1953): удержание базовой лексики ~86 % за 1000 лет, т. е. замена слова с интенсивностью λ = −ln(0,86)/1000 ≈ 1,5·10⁻⁴ в год. Звуковой закон — в среднем раз в 150 лет на язык (наш параметр, не из литературы).

## Дерево языков

Язык-потомок рождается, когда группа (или кластер групп) изолирована от носителей родительского языка дольше 120 лет (нет групп с тем же языком в радиусе 6 клеток) или когда полития отделилась. Новому языку применяются 1–2 звуковых закона сразу, затем идёт обычный дрейф. `LanguageSplit(parent, child, group)`. Взаимопонятность двух языков = доля когнатов, у которых совпадает форма — она понижает скорость обмена идеями (вера, знание) между группами: `contact *= 0,3 + 0,7·intelligibility`.

Заимствования: при торговле и завоевании слово «бог», «вождь», «зерно» и т. п. может быть заимствовано (с вероятностью ∝ престижу источника) — `WordBorrowed`.

## Имена

Все имена — только через язык культуры: `Naming.Compose(lang, conceptA, conceptB?)` возвращает `Name { Native, Gloss }` (форма и перевод «букв. „Бросающий огонь“»). Имена:
- групп (народ «ТАВЕН», букв. «люди реки») — `народ` + признак местности;
- людей (пророки, вожди) — корень + суффикс;
- Создателя — из эпитетов, накопленных этой культурой (см. faith-creator.md);
- религий, святынь, политий, битв, городов;
- видов: виды до Пробуждения называются на праязыке первого разумного вида (как «первые натуралисты» назвали зверей).

Кириллическая транслитерация фонем для Хроники (`ш`, `ч`, `къ` для q, `х` для x, `нг` для ŋ, `ʼ` для гортанной смычки) плюс латиница для карт и отладки.

## Тесты

- Звуковые законы: `kati → tʃati` при палатализации; `bad → bat` при оглушении конечных; `apa → aba` при озвончении.
- Анатомия: вид без губ не имеет губных фонем ни в одном слове.
- Глоттохронология: за 1000 лет без звуковых законов доля сохранённых корней 0,80…0,92 на 500 прогонах.
- Детерминизм: один сид — одни имена.
- Разные виды → разные инвентари (дистанция Жаккара > 0,2 у разных сидов в среднем).
