# Э1. Планета

## Сетка

- Карта `W×H` (по умолчанию 512×256), долгота замкнута (цилиндр), широта от +90° (верх) до −90°.
- Эко-сетка: даунсэмплинг ×4 (128×64) для жизни, групп и политий. Каждая эко-клетка хранит средние значения своих 16 клеток карты.

## Параметры (`WorldParams`)

| Параметр | По умолчанию («Земля») | Влияние |
|---|---|---|
| `OceanFraction` | 0,62 | уровень моря как квантиль высот |
| `MeanTemperature` | 14 °C | сдвиг температуры |
| `AxialTilt` | 23,4° | амплитуда сезонов |
| `Tectonics` | 1,0 | число плит и высота гор |
| `StarBrightness` | 1,0 | ±°C через закон Стефана–Больцмана: ΔT ≈ T₀·(L^{1/4} − 1), T₀ = 288 K |
| `PlateCount` | 9 | |

Пресеты: Земля, Ледяной мир (−18 °C, океан 0,5), Архипелаг (океан 0,8, тектоника 1,4), Пустынный Марс (океан 0,25, осадки ×0,35), Хаос (тектоника 2, частые катастрофы, наклон 40°).

## Рельеф

1. Плиты: `PlateCount` центров (равномерно на цилиндре), каждая клетка принадлежит ближайшему центру с искажением расстояния шумом (неровные границы). У плиты: континентальная или океаническая (доля континентальных ≈ 1 − OceanFraction), вектор скорости.
2. Базовая высота: континентальная +0,35, океаническая −0,45.
3. Границы: для пары соседних клеток разных плит сходимость `c = (v_a − v_b)·n`. Сходящиеся (c > 0) — горный хребет: `h += Tectonics·0,9·c·exp(−d/σ)`, где d — расстояние до границы (σ ≈ 6 клеток), для океан–континент — горы на континентальной стороне, жёлоб на океанической. Расходящиеся — рифт (−0,2·|c|). Расстояние до границы считается двухпроходным BFS.
4. Шум: fBm 6 октав градиентного шума (собственная реализация, детерминированная), с доменной деформацией (Quilez, «Domain warping», 2002): `h += 0,45·fbm(p + 0,8·fbm2(p))`. Шум берётся в 3D на цилиндре (cos λ, sin λ, y), поэтому шва нет.
5. Уровень моря — квантиль `OceanFraction`; высота над морем масштабируется к 0…8 км, глубины к 0…−6 км.

## Климат

- Температура (годовая средняя): `T = T₀(φ) − 6,5·max(0, z_km) + ΔT_star + ΔT_current`, `T₀(φ) = MeanT + 13 − 42·sin²φ` (даёт ≈ 27 °C на экваторе и ≈ −29 °C на полюсе при MeanT = 14). Градиент 6,5 °C/км — стандартная атмосфера ICAO.
- Тёплое течение: прибрежные клетки на западных берегах материков в поясе 40–65° получают +4 °C × затухание вглубь материка (аналог Гольфстрима для запада Европы).
- Сезоны: амплитуда `A = 18·(tilt/23,4)·|sin φ|·(0,35 + 0,65·continentality)`, температура сезона s (0…3) `T_s = T + A·cos(2π(s/4)) ·sign(φ)`.
- Осадки: базовая по широте (ячейки Хэдли, Феррела, полярная): `P₀(φ) = 2200·exp(−(φ/12°)²) + 1100·exp(−((|φ|−55°)/15°)²) + 150`, минус субтропический минимум `−700·exp(−((|φ|−28°)/8°)²)`.
- Перенос влаги ветром: пассаты (|φ|<30°) дуют с востока, западные ветры (30–60°) — с запада, полярные восточные (>60°). По каждой строке идём по ветру 2 оборота: над океаном влага насыщается до `P₀`, над сушей выпадает 18 % влаги за клетку, на подъёме дополнительно `k_oro·Δz` (орографический эффект), за хребтом — дождевая тень (влаги не осталось). Итог `P = P₀·moisture_factor`.

## Биомы (Уиттекер)

Классификация по (T °C, P мм/год) по упрощённой диаграмме Whittaker (1975), «Communities and Ecosystems»; контрольные точки — в тесте:

| Биом | Условие |
|---|---|
| Лёд | T < −10 |
| Тундра | −10 ≤ T < −5 |
| Тайга | −5 ≤ T < 5, P ≥ 250 |
| Холодная пустыня | T < 5, P < 250 |
| Умеренный дождевой лес | 5 ≤ T < 20, P ≥ 2000 |
| Умеренный лес | 5 ≤ T < 20, P ≥ 900 |
| Лесостепь и кустарники | 5 ≤ T < 20, 500 ≤ P < 900 |
| Степь (умеренные травы) | 5 ≤ T < 20, 250 ≤ P < 500 |
| Пустыня | P < 250 при T ≥ 5, или P < 400 при T ≥ 20 |
| Саванна | T ≥ 20, 400 ≤ P < 1500 |
| Тропический сезонный лес | T ≥ 20, 1500 ≤ P < 2500 |
| Тропический дождевой лес | T ≥ 20, P ≥ 2500 |

Плюс служебные: глубокий океан, шельф, озеро, горы (z > 3,5 км — «высокогорье» как модификатор).

## Реки и озёра

- Заполнение впадин: Priority-Flood (Barnes, Lehman, Mulla 2014). Клетки, поднятые заполнением больше чем на 20 м, — озёра (если площадь ≥ 3), остальное — плоскость стока.
- Направление стока D8 по заполненной высоте; накопление стока = сумма `P` вверх по течению (обход по убыванию высоты — стабильная сортировка). Река там, где накопление > порога (квантиль 0,97 суши).

## Ресурсы

- Первичная продукция по модели Майами (Lieth 1975): `NPP_T = 3000/(1+e^{1,315−0,119T})`, `NPP_P = 3000·(1−e^{−0,000664P})`, `NPP = min(NPP_T, NPP_P)` г/м²/год.
- Плодородие для земледелия: `NPP/3000 × (1 + 0,6·river) × (1 − slope)`, обнулено во льдах и пустынях.
- Руды: вероятность ∝ близость к границам плит (настоящим и «древним» — второй набор центров плит из того же потока RNG).
- Рыба: шельф и реки. Камень: горы. Лес: лесные биомы.
- Одомашниваемые растения: в клетках степи, лесостепи, саванны и умеренного леса с плодородием > 0,4 (по мотивам Даймонда, «Ружья, микробы и сталь»).

## Динамика (эпоха истории)

- Аномалия осадков по регионам 16×16 клеток эко-сетки: AR(1) `a_t = 0,6·a_{t−1} + 0,8·ε`, засуха при `a < −1,6` (≈ 5 % лет), продолжительность — пока не вернётся выше −0,8. Событие `NaturalDrought(region, magnitude=−a)`.
- Землетрясения: на границах плит, вероятность 0,004/год на регион × Tectonics.
- Кометы: одна-две периодические кометы с периодом 40–120 лет (`Comet`). Умная культура может заметить период → натурализм.
- Сезоны в годовом тике учитываются как множитель урожая по сезонной амплитуде (короткое лето севера).

## События

Порождает: `PlanetFormed`, `NaturalDrought`, `DroughtEnded`, `Earthquake`, `Comet`. Слушает: вмешательства `Drought`, `Rain`, `Meteor` (меняет осадки, высоту, температуру).

## Тесты

- Уиттекер: контрольные точки (25 °C, 3000 мм → тропический дождевой лес; −5 °C, 300 мм → тайга; 25 °C, 100 мм → пустыня; 12 °C, 1200 → умеренный лес; 15 °C, 350 → степь …).
- Градиент: клетка на 2 км выше той же широты на 13 °C холоднее.
- Дождевая тень: в синтетическом мире с хребтом поперёк западных ветров осадки за хребтом ниже, чем перед ним.
- Реки текут вниз: высота каждой речной клетки ≥ высоте следующей по течению.
- Доля океана в пределах ±1 % от параметра.
- Генерация 512×256 ≤ 3 с (бенчмарк).
