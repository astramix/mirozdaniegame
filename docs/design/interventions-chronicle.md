# Сценарные вмешательства и Хроника

## Сценарий `--script file.json`

```json
{
  "name": "Засуха и пророк",
  "interventions": [
    { "year": 150, "type": "drought", "target": "largest_group", "radius": 4, "duration": 3 },
    { "year": 220, "type": "lightning", "target": "polity_capital:0" },
    { "year": 260, "type": "harvest", "target": "group:3" },
    { "year": 300, "type": "vision", "target": "random_group", "message": "peace" },
    { "year": 400, "type": "meteor", "target": "cell:60,30", "magnitude": 1.0 },
    { "year": 450, "type": "rain", "target": "largest_group" },
    { "year": -100, "type": "spark", "target": "best_species" }
  ]
}
```

- `year` — год после Пробуждения; отрицательный год −N — тик N эпохи жизни, то есть N тыс. лет после зарождения жизни (только `spark`, `meteor`). *Отступление от первой версии дизайна: «до конца эпохи» нельзя знать заранее, Пробуждение наступает в разное время.*
- `target`: `largest_group`, `random_group`, `group:N` (N-я группа по порядку основания, если она жива; иначе ближайшая живая), `polity_capital:N`, `religion_center:N`, `cell:x,y` (эко-сетка), `best_species`.
- Типы и эффекты:
  - `drought` — осадки ×0,3 в радиусе на `duration` лет (anomaly 0,4);
  - `rain` — осадки ×1,6 в радиусе (снимает засуху; anomaly 0,5);
  - `lightning` — удар в клетку; если в ней лидер политии — гибель лидера; иначе гибель 1–3 % населения и пожар (anomaly 0,9);
  - `harvest` — урожай ×2,2 на 1 год в радиусе 1 (anomaly 0,8, если вокруг голод);
  - `vision` — пророк в группе, `message` ∈ {peace, war, love, wrath, knowledge, obedience, freedom} сдвигает доктрину культа;
  - `meteor` — кратер (высота −), гибель групп в радиусе 2, потери в радиусе 6, похолодание −3 °C на 5 лет в радиусе 12 (anomaly 0,5);
  - `spark` — снижает порог разума выбранного вида на 0,15.
- Разбор через `System.Text.Json` в Core; неизвестный тип — ошибка с понятным сообщением. Порядок применения — по году, затем по порядку в файле.
- Каждое вмешательство публикует событие `Intervention(type)` и затем «природное» последствие с флагом `ByCreator` (культуры видят только последствие; Хроника знает правду и отмечает её курсивом «(рука Создателя)»).

## Хроника `out/<seed>/chronicle.md`

Строится в конце прогона из журнала событий и итогового состояния мира (имена берутся из языков; поэтому даже виды, жившие до Пробуждения, названы словами первого разумного народа).

Структура:
1. Заголовок: имя мира (на праязыке, «букв. …»), сид, пресет, сценарий.
2. «Сотворение» — планета: доля океана, материки, самые высокие горы, великие реки (имена — на праязыке).
3. «Эпоха жизни» — даты «за N тыс. лет до Пробуждения»: появление жизни, рождение и вымирание видов (не больше 25 строк), «искра».
4. «Пробуждение».
5. Века «после Пробуждения»: по каждому веку не больше 40 записей, отобранных по значимости (`Magnitude` × вес типа), но события с участием Создателя и цепочки причинности сохраняются всегда. Цепочки (`Cause`) пишутся вместе: «Из-за засухи 200 года …».
6. «Имена Создателя»: таблица по культурам: имя, перевод, эпитеты, позиция, вера.
7. «Веры мира»: дерево вер и расколов с доктриной словами.
8. «Языки»: дерево языков и эволюция 5 слов по ветвям.
9. «Глоссарий»: все термины с переводами.
10. «Итог»: население, политии, уровень Кардашёва, энергия Создателя.

Тексты — шаблоны с вариантами (выбор по RNG потока Chronicle от id события, поэтому стабилен), согласование числительных (`1 год / 2 года / 5 лет`), головное существительное + имя в именительном («народ Тавен», «вера Ашур»), чтобы не склонять процедурные имена. Тон: у культур с высокой гневностью веры — «пророческий» вариант шаблона толкования.

Размер: ограничен отбором до ≈ 150 КБ на 1000 лет.

## Тесты

- Сценарий парсится, ошибки понятны.
- Хроника детерминирована (SHA-256 двух прогонов совпадает).
- В Хронике нет строк-заглушек `{` `}` и «null».
- Каждое вмешательство из сценария упомянуто в Хронике.
