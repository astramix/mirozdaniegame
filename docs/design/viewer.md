# Минимальный Godot-зритель (черновик Э1.5/Э4.5)

**Роль.** Показать мир автору: карта, слои, Хроника, силы Создателя.

- `game/` — Godot 4.4 .NET, `Mirozdanie.Game.csproj` ссылается на Core.
- `Main.tscn`: при старте генерируется мир (сид из поля ввода, по умолчанию 42) и прогоняется эпоха жизни и первые 300 лет истории в фоновом потоке (`Task.Run`), пока на экране надпись «Мир сотворяется…».
- Карта: 8×4 чанка по 64×64 клеток (`Sprite2D` с `ImageTexture` на каждый чанк), `Camera2D` с зумом колесом и панорамой правой кнопкой. Чанк перерисовывается, только если изменился его слой (сравнение версии слоя).
- Слои (кнопки): биомы, высоты, языки, религии, политии, отношение к Создателю.
- Лента Хроники справа (`RichTextLabel`), последние 60 записей; кнопки «+10 лет», «+100 лет», «пауза/пуск».
- Панель 4 сил Создателя: засуха, молния, чудо урожая, видение. Клик по силе, затем по карте → вмешательство в очередь команд Core (`World.Enqueue(Intervention)`), применяется на следующем тике.
- Окно обращения пророка: когда в событиях появляется `ProphetBorn` или `PrayerUnanswered` крупной группы, всплывает окно: имя пророка, реплика на его языке (слова из лексикона: «X, ты-слышишь, мы-голодаем») и перевод.
- Дымовой тест: `godot --headless --path game --quit-after 300`.

**Слушает:** снимок `WorldSnapshot`. **Порождает:** команды вмешательств (через очередь, детерминированно применяются в начале тика).
